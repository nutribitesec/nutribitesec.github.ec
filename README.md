# Nutribites — landing oficial

Sitio estático de una sola página (`index.html`, con imágenes y estilos incluidos).

## Publicar en GitHub Pages
1. En el repositorio: **Settings → Pages**.
2. En *Build and deployment* elige **Deploy from a branch**, rama `main`, carpeta `/ (root)`.
3. Guarda. Cada `git push` a `main` vuelve a publicar el sitio.
