# Nutribites — landing oficial

Sitio estático de una sola página (`index.html`, con imágenes y estilos incluidos).

## Publicar en Netlify desde GitHub
1. Sube esta carpeta a un repositorio nuevo en GitHub.
2. En Netlify: **Add new site → Import an existing project → GitHub** y elige el repositorio.
3. Build command: *(vacío)* · Publish directory: `.`
4. Deploy. Cada `git push` a la rama principal vuelve a publicar el sitio.
